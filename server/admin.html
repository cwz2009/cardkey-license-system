脚本验证（SH 加卡密）⌄
给 SH 文件加卡密验证 生成带验证门的 sh，验证通过才执行原脚本
把你的 sh 脚本原内容贴到下方，点击「生成带验证的 SH」后，会自动在开头插入一段「卡密验证门」：运行时先让你输入邮箱+卡密，验证通过才执行你原来的脚本。验证复用同一套卡密（和卡密 App 通用）。需在已获取 root 或装有 Termux 的安卓设备上运行，且设备能联网访问上方服务器地址（默认已指向本服务器）。
把下载的 .sh 传到手机，在 Termux 里 bash xxx.sh 运行（需设备已安装 curl），按提示输入邮箱+卡密即可。

SMTP 发信配置 用于注册验证码等邮件
填写一个能发信的邮箱（QQ / 163 / 企业邮箱均可）。需先在邮箱设置里开启 SMTP 服务并获取「授权码」填入下方（不是邮箱登录密码）。
💡 配置与「发送测试邮件」需要你能登录该邮箱并获取 SMTP 授权码；若当前无法登录邮箱，则暂无法完成配置与验证。
